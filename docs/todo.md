## 확인 기록

- 2026-11-04: 파이썬 로더가 iframe 없는 `py-bookmarklet.js`를 넣게 바꾸고, 필터를 누르면 화면만 바꾸는 가짜 페이지로 확인했다. iframe 없이 패널이 떴고, "모두 제외"는 fo를 붙여 페이지를 새로 연 뒤 다시 들어온 코드가 제외 셋을 이어서 눌렀다. 쿠팡 선택 뒤 자동 복사 내용(x / URL / 700 / 270)도 맞았다. NPCS는 `target="_blank" rel="noopener"` 링크, `window.open`, 직접 연 탭 모두 묶어보기가 꺼졌고 패널은 뜨지 않았다. 실제 네이버에서는 확인하지 못했다.

- 2026-11-04: 파이썬 로더를 가짜 페이지와 임시 프로필로 확인했다. 시작할 때 열린 검색 탭, 같은 탭의 새 검색, 새 탭에 패널이 하나씩 들어갔고, 카탈로그 페이지에는 넣지 않았다. 원격 main의 `bookmarklet.js`도 받아졌다. Chrome을 닫으니 로더도 끝났다. 실제 네이버와 자동화 프로필 로그인은 확인하지 못했다.

- 2026-11-04: 감지기를 추가했다. 실제 네이버 탭을 읽기만 해서 상품 카드 셀렉터로 링크 25개가 잡히고 몰 번호가 쿠팡 필터 값(613264)과 같음을 확인했다. 상품 카드를 넣은 가짜 페이지에서 이마트, 컬리 ON과 자동 펼침, 컬리 클릭 시 스크롤과 1.2초 칠하기, 손으로 접기, 모두 OFF일 때 자동 접힘이 동작했다. 몰 번호는 흐린 명세 사진에서 읽은 값이라 원본과 맞춰 보지 못했다.

- 2026-11-04: 로더를 가짜 페이지에서 실행했다. GitHub `main`의 `bookmarklet.js`를 받아 "MSV Helper" 패널과 iframe이 떴고, 한 번 더 눌러도 패널과 iframe은 하나씩이었다. raw 응답은 `max-age=300`이고 쿼리를 붙여도 캐시를 탔다. 실제 네이버, 회사망, 실패 알림은 확인하지 못했다.
