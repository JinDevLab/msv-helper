# 할 일

- 실제 네이버에서 "중고 제외"가 손으로 누른 것과 같은 결과를 내는지 확인한다.
- "모두 제외"나 해외직구·중고·렌탈을 차례로 제외했을 때 셋 다 적용되는지, 마지막 하나만 남는지 확인한다. 하나만 남으면 셋을 같이 제외할 다른 방법을 정한다.
- 실제 네이버에서 쿠팡만 선택한 뒤 "전체" 옆 숫자가 쿠팡 수로 바뀌는지, 패널의 전체 수(전)·쿠팡 수(후)가 화면과 같은지 확인한다. 손으로 쿠팡을 고른 뒤 패널을 열면 전체 수 자리에 쿠팡 수가 들어간다.
- 쿠팡 필터를 누른 뒤 자동 복사가 실제로 되는지 확인한다. 저장 뒤 결과를 기다리는 몇 초 사이에 브라우저가 클립보드 쓰기를 막을 수 있다.
- 실제 네이버에서 "쿠팡만 선택"이 다른 몰 체크를 풀고 쿠팡만 저장하는지 확인한다. 다른 탭(백화점/홈쇼핑 등)에 체크된 몰은 지금 풀지 않는다.
