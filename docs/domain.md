# 도메인

## 용어

- **MSV:** 팀의 시장조사 오퍼레이터.
- **capa:** 오퍼레이터의 생산성. 이 프로젝트의 목표는 작업을 단순하게 만들어 capa를 높이는 것이다.
- **n total:** 네이버 가격비교 검색 결과의 "전체" 탭(`search.shopping.naver.com/search/all`)에서 하는 시장조사.
- **혼재:** 검색 결과에 섞인, 타겟과 다른 제품.
- **전체 수 / 쿠팡 수:** 판매처 탭 "전체" 옆 숫자. 쿠팡만 선택하기 전 값이 전체 수, 선택한 뒤 값이 쿠팡 수다.

## n total 작업 순서

1. 타겟 제품을 검색한다(`fo=true`).
2. 해외직구·중고·렌탈을 제외한다. 이 셋은 대상이 아니다.
3. 오퍼레이터가 결과를 보며 혼재를 확인하고, 검색어에 `-단어`를 붙여 뺀다. 혼재가 다 빠질 때까지 반복한다. 무엇을 뺄지는 사람이 정한다.
4. 혼재가 다 빠지면 전체 수를 확인한다.
5. 쇼핑몰선택에서 쿠팡만 선택하고 쿠팡 수를 확인한다.
6. 칸반(스프레드시트)에 검색어, URL, 전체 수, 쿠팡 수 순서로 붙이고 마무리한다. 쿠팡 외 판매처 수(전체 수 − 쿠팡 수)는 칸반에서 계산한다.

혼재 제거는 사람이 판단하는 단계라서, 2단계와 5단계를 하나로 이어 자동으로 실행하지 않는다.

## 네이버 가격비교 규칙

- **`fo=true`:** URL 쿼리에 붙이면 검색어 그대로만 검색한다("~로만 검색하기"). filter only의 약자로 보인다.
- **상품타입 필터:** 검색 결과 위 "상품타입(전체)" 드롭다운이다. 검색어에 따라 없거나 일부 항목만 있다. 페이지 데이터(`__NEXT_DATA__`)의 `subFilters` 중 `name: "productType"`이 정의다.

| 항목 | `filter_value_id` (`paramName`) | `excludeParam` |
|---|---|---|
| 해외직구보기 / 해외직구제외 | `agency` / `exagency` | 서로 반대쪽 |
| 중고보기 / 중고제외 | `used` / `exused` | 서로 반대쪽 |
| 렌탈보기 / 렌탈제외 | `rental` / `exrental` | 서로 반대쪽 |

- **드롭다운 DOM:** 토글과 항목이 모두 `a[data-shp-area-id="pdtype"]`이다. 항목에만 `data-shp-contents-dtl`이 있고, 그 JSON의 `filter_value_id`가 위 값이다. 드롭다운이 닫혀 있어도 항목은 DOM에 있고, 열리면 `subFilter_select_box__…`에 `open` 클래스가 붙는다. `__…` 뒤 해시는 배포마다 바뀔 수 있어 쓰지 않는다.
- **여러 개 선택:** 필터 정의는 `multiSelect: false`지만, 실제 드롭다운에서 해외직구제외와 중고제외를 차례로 누르면 토글 글자가 "해외직구제외,중고제외"가 된다.
- **라우터 이동 금지:** `paramName`을 URL에 붙이고 Next.js 라우터로 이동하면 검색 결과가 모두 사라졌다. 같은 주소를 일반 페이지 로드로 여는 것은 `mall`에서는 동작했다.

- **쇼핑몰선택:** 토글은 `a[data-shp-area-id="shoptype"]`이다. 누르면 옆 레이어(`subFilter_layer_mall__…`)에 `open` 클래스가 붙고, 그때 몰 목록을 불러온다. 위에 탭(`li[data-shp-area-id="shoptab"]`, 기본은 "오픈마켓/종합몰")이 있고 아래에 저장(`shoptypesave`)·취소 버튼이 있다.
- **몰 목록 항목:** `li[data-shp-area-id="shop"]` 안에 체크박스와 label이 있다. `data-shp-contents-dtl`의 `filter_value_id`가 몰 번호다. 쿠팡은 `613264`로 "오픈마켓/종합몰" 탭에 있다.

## 북마클릿 동작

- **한 번 누르기 (iframe):** 북마클릿을 누르면 지금 페이지 위에 같은 주소를 화면 전체 iframe으로 띄우고 패널은 바깥 페이지에 둔다. 모든 조작은 iframe 안의 문서에 한다. 네이버는 `X-Frame-Options`와 CSP 헤더가 없어(2026-11-04 확인) 같은 사이트 iframe이 열린다.
- **`fo=true` 유지:** iframe 주소에 `fo=true`가 없으면 붙여서 연다. 0.5초마다 iframe 주소를 보고, `/search/all`에서 새로 검색해 `fo=true`가 빠지면 다시 붙인다. 바깥 주소창은 iframe 주소로 맞춘다.
- **닫기:** 패널의 ×를 누르면 iframe에서 보던 주소를 바깥 페이지로 다시 연다.
- **패널:** 예전에 쓰던 "N Total Helper" 모양을 따른다. 1번 `fo=true` 적용 상태, 2번 해외직구·중고·렌탈 제외, 모두 제외, 쿠팡 필터(상태: 적용됨 / 가능 / 해당없음), 3번 전체 수(전)·쿠팡 수(후)와 복사 버튼들이다. 헤더의 −로 접고 ×로 닫는다.
- **상태 판단:** 제외는 주소에 `exused=true` 같은 값이 있으면 적용됨, 드롭다운에 항목이 있으면 가능, 없으면 해당없음이다. 쿠팡 필터는 패널에서 쿠팡을 고른 뒤면 적용됨이고, 검색어가 바뀌면 처음으로 돌아간다.
- **제외:** 사람이 하듯 토글을 누르고 `filter_value_id`로 찾은 항목을 클릭한 뒤, 주소나 토글 글자가 바뀔 때까지 기다린다. 클릭 뒤 DOM이 새로 그려지므로 항목은 매번 다시 찾는다. 한 줄씩 따로 누르거나, "모두 제외"로 아직 적용 안 된 것만 차례로 누른다. "모두 제외"는 마지막에 지금 상품타입을 보여준다.
- **쿠팡만 선택:** 지금 주소에서 `mall`만 `613264`로 바꾼 주소로 iframe을 새로 연다. 쇼핑몰선택에서 쿠팡만 저장했을 때와 같은 결과(쿠팡 칩, 쿠팡 상품, "전체" 숫자 변화)가 나온다. 새 페이지에서 "전체" 숫자를 읽을 수 있으면 끝난 것으로 본다.
- **가짜 클릭 차단:** 스크립트의 `.click()`은 `isTrusted=false`인 이벤트다. 이걸로 필터를 바꾸면 화면의 선택 상태는 바뀌지만, 검색 API(`/api/search/all`)가 418을 돌려주고 주소와 결과가 그대로 남는다. 저장 직후 `ncpt.naver.com` 토큰 요청이 나간다. 같은 시간에 요청을 많이 보내면 보안 확인(캡차) 화면이 뜬다.
- **칸반용 복사:** "쿠팡 필터 선택"이 끝나면 작업이 끝난 것으로 보고, 검색어·URL·전체 수·쿠팡 수를 탭으로 나눈 한 줄을 클립보드에 자동으로 넣는다. 시트에 붙이면 네 칸에 나뉘어 들어간다. "📊 스프레드시트 전체 복사"로 같은 줄을 다시 복사하고, 타이틀·URL·숫자는 따로도 복사할 수 있다.
  - 검색어는 URL의 `query`를 푼 값이고 `-단어`도 들어간다.
  - URL은 쿠팡을 고르기 전 주소다.
  - 숫자는 쉼표를 뺀다.
  - 클릭 뒤 시간이 지나 브라우저가 자동 복사를 막으면, "📊 스프레드시트 전체 복사"를 다시 누른다.
