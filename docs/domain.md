# 도메인

## 용어

- **MSV:** 팀의 시장조사 오퍼레이터.
- **capa:** 오퍼레이터의 생산성. 이 프로젝트의 목표는 작업을 단순하게 만들어 capa를 높이는 것이다.
- **n total:** 네이버 가격비교 검색 결과의 "전체" 탭(`search.shopping.naver.com/search/all`)에서 하는 시장조사.

## 네이버 가격비교 규칙

- **`fo=true`:** URL 쿼리에 붙이면 검색어 그대로만 검색한다("~로만 검색하기"). filter only의 약자로 보인다. 북마클릿은 이 값이 없으면 붙여서 페이지를 다시 열고, 있을 때만 패널을 띄운다.
- **상품타입 필터:** 검색 결과 위 "상품타입(전체)" 드롭다운에 해외직구보기·해외직구제외·중고보기·중고제외·렌탈보기·렌탈제외가 있다. 검색어에 따라 드롭다운이 없거나 일부 항목만 있다.

## 북마클릿 동작

- **제외 버튼:** 해외직구·중고·렌탈 제외는 URL을 직접 고치지 않고, 드롭다운 항목을 실제로 누른 것처럼 클릭한다. 항목은 클래스 이름이 아니라 보이는 글자로 찾는다.
