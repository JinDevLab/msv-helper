# 도메인

## 용어

- **MSV:** 팀의 시장조사 오퍼레이터.
- **capa:** 오퍼레이터의 생산성. 이 프로젝트의 목표는 작업을 단순하게 만들어 capa를 높이는 것이다.
- **n total:** 네이버 가격비교 검색 결과의 "전체" 탭(`search.shopping.naver.com/search/all`)에서 하는 시장조사.
- **혼재:** 검색 결과에 섞인, 타겟과 다른 제품.
- **전체 수 / 쿠팡 수:** 판매처 탭 "전체" 옆 숫자. 쿠팡만 선택하기 전 값이 전체 수, 선택한 뒤 값이 쿠팡 수다.

## n total 작업 순서

1. 타겟 제품을 검색한다(`fo=true`).
2. 해외직구·중고·렌탈을 제외한다. 이 셋은 대상이 아니다.
3. 오퍼레이터가 결과를 보며 혼재를 확인하고, 검색어에 `-단어`를 붙여 뺀다. 혼재가 다 빠질 때까지 반복한다. 무엇을 뺄지는 사람이 정한다.
4. 혼재가 다 빠지면 전체 수를 확인한다.
5. 쇼핑몰선택에서 쿠팡만 선택하고 쿠팡 수를 확인한다.
6. 칸반(스프레드시트)에 검색어, URL, 전체 수, 쿠팡 수 순서로 붙이고 마무리한다. 쿠팡 외 판매처 수(전체 수 − 쿠팡 수)는 칸반에서 계산한다.

혼재 제거는 사람이 판단하는 단계라서, 2단계와 5단계를 하나로 이어 자동으로 실행하지 않는다.

## 네이버 가격비교 규칙

- **`fo=true`:** URL 쿼리에 붙이면 검색어 그대로만 검색한다("~로만 검색하기"). filter only의 약자로 보인다.
- **상품타입 필터:** 검색 결과 위 "상품타입(전체)" 드롭다운이다. 검색어에 따라 없거나 일부 항목만 있다. 페이지 데이터(`__NEXT_DATA__`)의 `subFilters` 중 `name: "productType"`이 정의다.

| 항목 | `filter_value_id` (`paramName`) | `excludeParam` |
|---|---|---|
| 해외직구보기 / 해외직구제외 | `agency` / `exagency` | 서로 반대쪽 |
| 중고보기 / 중고제외 | `used` / `exused` | 서로 반대쪽 |
| 렌탈보기 / 렌탈제외 | `rental` / `exrental` | 서로 반대쪽 |

- **드롭다운 DOM:** 토글과 항목이 모두 `a[data-shp-area-id="pdtype"]`이다. 항목에만 `data-shp-contents-dtl`이 있고, 그 JSON의 `filter_value_id`가 위 값이다. 드롭다운이 닫혀 있어도 항목은 DOM에 있고, 열리면 `subFilter_select_box__…`에 `open` 클래스가 붙는다. `__…` 뒤 해시는 배포마다 바뀔 수 있어 쓰지 않는다.
- **여러 개 선택:** 필터 정의는 `multiSelect: false`지만, 실제 드롭다운에서 해외직구제외와 중고제외를 차례로 누르면 토글 글자가 "해외직구제외,중고제외"가 된다.
- **라우터 이동 금지:** `paramName`을 URL에 붙이고 Next.js 라우터로 이동하면 검색 결과가 모두 사라졌다. 같은 주소를 일반 페이지 로드로 여는 것은 동작했지만, 필터마다 페이지를 새로 열면 캡차가 자주 떴다.

- **쇼핑몰선택:** 토글은 `a[data-shp-area-id="shoptype"]`이다. 누르면 옆 레이어(`subFilter_layer_mall__…`)에 `open` 클래스가 붙고, 그때 몰 목록을 불러온다. 위에 탭(`li[data-shp-area-id="shoptab"]`, 기본은 "오픈마켓/종합몰")이 있고 아래에 저장(`shoptypesave`)·취소 버튼이 있다.
- **몰 목록 항목:** `li[data-shp-area-id="shop"]` 안에 체크박스와 label이 있다. `data-shp-contents-dtl`의 `filter_value_id`가 몰 번호다. 쿠팡은 `613264`로 "오픈마켓/종합몰" 탭에 있다.

## 북마클릿 동작

- **한 번 누르기 (iframe):** 북마클릿을 누르면 지금 페이지 위에 같은 주소를 화면 전체 iframe으로 띄우고 패널은 바깥 페이지에 둔다. 모든 조작은 iframe 안의 문서에 한다. 네이버는 `X-Frame-Options`와 CSP 헤더가 없어(2026-11-04 확인) 같은 사이트 iframe이 열린다.
- **`fo=true`는 버튼으로:** n total이 아닌 작업에서는 `fo=true`가 필요 없어서 자동으로 붙이지 않는다. 화면에 누를 곳이 없는 옵션이라 주소로 붙인다(페이지 로드 한 번). "모두 제외"는 `fo=true`가 없으면 먼저 붙이고 제외를 차례로 누른다. `fo=true`로 검색어 그대로 찾은 상품이 0건이면 네이버는 판매처 탭, 상품타입, 쇼핑몰선택 없이 "찾으시는 상품과 유사한 상품을 노출합니다" 목록을 보여준다(`__NEXT_DATA__`의 `orgQueryTotal`이 0). 이때는 제외를 건너뛰고 상태 줄에 "fo 결과 0건"을 남긴다. 복사는 하지 않는다. 새로 검색해 `fo=true`가 빠지면 다시 누른다. 바깥 주소창은 0.5초마다 iframe 주소로 맞춘다.
- **닫기:** 패널의 ×를 누르면 iframe에서 보던 주소를 바깥 페이지로 다시 연다.
- **패널:** 머리에 "MSV Helper"와 −·×, 그 아래 상태 칩(fo·해외·중고·렌탈·쿠팡)을 두고, 그 아래에 칸반에 붙는 순서대로 검색어·URL·전체·쿠팡 칸을 시트 한 행처럼 보여준다. 그 아래가 "모두 제외"·"쿠팡 선택"과 "시트 한 줄 복사"다. 접어도 칩은 보인다. 상태 줄은 실패했을 때만 보인다. 성공은 칩, 숫자, 복사 점선으로 알 수 있다. 칩을 누르면 그 필터 하나만 켜거나 끈다(끄면 주소에서 그 파라미터를 뺀다). 쿠팡 칩을 켜는 것은 "쿠팡 선택"과 같고, 끄면 `mall`을 빼고 저장해 둔 전체 수도 지운다. 이 검색어에 없는 항목의 칩은 누를 수 없다. 맨 아래에 개발용 진단·덤프를 작게 둔다.
- **상태 판단:** 칩이 초록이면 적용됨, 회색 테두리면 아직, 흐리게 줄이 그어져 있으면 이 검색어에 없는 항목이다. 제외는 주소에 `exused=true` 같은 값이 있으면 적용됨, 드롭다운에 항목이 있으면 아직이다. 쿠팡은 주소에 `mall=613264`가 있거나 패널에서 쿠팡을 고른 뒤면 적용됨이다. 패널이 쿠팡을 고른 뒤 주소가 조금이라도 바뀌면(같은 검색어로 재검색해도 네이버가 쿠팡을 풀고 주소를 바꾼다) 저장해 둔 쿠팡 선택 전 값을 지운다.
- **제외:** 드롭다운 토글을 누르고 `filter_value_id`로 찾은 항목을 누른 뒤, 주소나 토글 글자가 바뀔 때까지 기다린다. 그 뒤 이어서 누를 항목이 남았으면 "전체" 숫자가 바뀌길 최대 1초 기다린다. 제외할 상품이 없으면 숫자가 그대로라 1초를 다 쓴다. 마지막 항목 뒤에는 기다리지 않는다. 클릭 뒤 DOM이 새로 그려지므로 항목은 매번 다시 찾는다. 적용된 칩을 누르면 같은 항목을 다시 누른다(실제 네이버에서 풀리는지는 확인 못 함). 여러 개를 차례로 누르면 드롭다운이 "해외직구제외,중고제외"처럼 같이 적용된다.
- **쿠팡만 선택:** 쇼핑몰선택 레이어를 열고 목록을 기다린 뒤, 쿠팡만 체크되게 label을 누르고 저장을 누른다. 쿠팡이 1초 안에 안 보이면 "오픈마켓/종합몰" 탭을 누르고 0.5초 더 기다린다(합쳐 1.5초). 그래도 없으면 이 검색어에는 쿠팡이 없는 것으로 보고, 연 레이어를 닫은 뒤 쿠팡 수를 0으로 넣어 한 줄을 복사한다. 상태 줄에 "쿠팡 없음: 쿠팡 수 0으로 복사"가 남는다. 쿠팡을 골랐는데 결과가 0건이면 판매처 탭 "전체" 옆 숫자가 사라지고 `noResult` 안내가 뜬다. 이때도 쿠팡 칸과 복사 값은 0이다. 쿠팡 칩을 끄면 체크를 모두 풀고 저장한다.
- **클릭 방식:** 스크립트의 `.click()` 하나만 보내면 화면의 선택 상태는 바뀌지만 검색 API(`/api/search/all`)가 418을 돌려주고 결과가 그대로 남는다. 저장 직후 `ncpt.naver.com` 토큰 요청이 나간다. 그래서 예전 확장 프로그램처럼 mouseenter·mouseover·mousedown·mouseup·click을 차례로 보낸다. 이렇게 보낸 "중고제외"는 실제 네이버에서 200으로 반영됐다(한 번 확인). 네이버가 검사를 바꾸면 다시 막힐 수 있다.
- **칸반용 복사:** "쿠팡 선택"이 끝나면 작업이 끝난 것으로 보고, 검색어·URL·전체 수·쿠팡 수를 탭으로 나눈 한 줄을 클립보드에 자동으로 넣는다. 시트에 붙이면 네 칸에 나뉘어 들어간다. "시트 한 줄 복사"로 같은 줄을 다시 복사한다. 칸 하나를 누르면 그 값만 복사한다. 복사한 칸에는 시트처럼 파란 점선이 1.5초 보인다. 값이 없는 칸은 복사하지 않는다.
- **감지기:** 다른 작업에서 놓친 다른 유통사 상품을 n total 작업 중에 찾는 마지막 확인용이다. 오른쪽 아래 작은 어두운 창에 이마트, 롯데마트, 컬리, 올리브영, 지그재그, 오늘의집, 펫프렌즈의 ON/OFF를 보여준다. 지금 iframe에 보이는 페이지의 상품 카드 링크(`[class^="product_item"] a[data-shp-contents-provider-id]`)에서 몰 번호를 모아, 그 몰 번호가 하나라도 있으면 ON이다. 몰 번호는 쇼핑몰선택의 `filter_value_id`와 같다(쿠팡 613264로 확인). 처음에는 접혀 있고, 하나라도 ON이 되면 펼치고 모두 OFF가 되면 접는다. ON인 줄을 누르면 그 몰의 첫 상품으로 스크롤하고 1.2초 동안 노랗게 칠한다. 쿠팡만 선택한 뒤에는 모두 OFF가 되는데, 그때는 볼 필요가 없다.
  - 검색어는 검색창(`input[data-shp-area-id="input"]`)의 값이라 `-단어`도 들어간다. 주소의 `query`는 필터를 바꾸면 `-단어`가 빠지고 `xq`로 따로 가서 쓰지 않는다. 검색창이 없을 때만 주소의 `origQuery`(없으면 `query`)를 쓴다.
  - URL은 쿠팡을 고르기 전 주소다.
  - 숫자는 쉼표를 뺀다.
  - 클릭 뒤 시간이 지나 브라우저가 자동 복사를 막으면, "시트 한 줄 복사"를 다시 누른다.
